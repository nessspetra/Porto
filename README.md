# Professional Frontend Portfolio — Gayus Jones Petra

A high-impact, professional, and modern frontend developer portfolio built with HTML5, CSS3, and JavaScript.

## 🚀 Live Demo
[View Live Portfolio](https://nessspetra.github.io/Porto/) (Requires GitHub Pages to be enabled)

## ✨ Features
- **Modern UI/UX**: Premium design with glassmorphism, animated background orbs, and custom interactive cursor.
- **Data-Driven Architecture**: Powered by JavaScript OOP for easy content management (skills, projects, experience).
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop views.
- **ATS-Friendly**: Semantically structured HTML for better SEO and compatibility with recruitment systems.
- **Smooth Navigation**: Silk-smooth scrolling and scroll-aware navigation highlights.
- **Interactive Contact Form**: Simulated form submission with validation and loading states.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3 (Custom Variables), JavaScript (ES6+)
- **Styling Framework**: Bootstrap 5 (Grid & Utilities)
- **Icons**: Bootstrap Icons
- **Fonts**: Google Fonts (Syne, Bricolage Grotesque, JetBrains Mono)

## 📁 Project Structure
```text
├── index.html                  # Main structure & content
├── style.css                   # Premium styling & animations
├── app.js                      # Application logic & dynamic rendering
└── CV_Gayus Jones Petra.pdf    # Downloadable resume
```

## 📝 How to Update Content
To update skills, projects, or experience, simply edit the `PortfolioData` class in `app.js`.
